# 💖 Pure Dating Bot — Telegram Анонимные Знакомства

Современный, быстрый и отзывчивый Telegram-бот для знакомств по концепции «вошёл, выбрал и общайся».

---

## 🌟 Ключевые возможности

1. **⚡ Быстрая регистрация (30 секунд)**:
   - Пол, предпочтения поиска, возраст, город, описание.
   - Подборка из 40 фирменных аватаров по умолчанию или загрузка собственного фото.

2. **🔍 Умная лента анкет & Мэтчинг**:
   - Эргономичные кнопки в 2 ряда во всю ширину экрана.
   - Оценки: ❤️ Лайк, 💌 Сообщение, 👎 Пропустить.
   - Мгновенные уведомления о взаимной симпатии со ссылкой на контакт.

3. **👥 Экосистема и живая база**:
   - 200 сгенерированных фотореалистичных виртуальных анкет (100 парней + 100 девушек) с уникальными описаниями и аватарами для мгновенного старта и видимости активности.

4. **🔒 Приватный режим и защита**:
   - Возможность включения пароля на доступ к боту через админ-панель.
   - Индивидуальная настройка паролей пользователей.

5. **📊 Кабинет администратора (`/admin`)**:
   - Живая статистика: общее число пользователей, активные онлайн, заходы за сегодня/неделю.
   - Управление паролем доступа.
   - Рассылки и управление базой.

6. **☁ Готовность к работе 24/7 автономно**:
   - Встроенный веб-сервер проверки здоровья (`aiohttp`) для бесплатного хостинга (Render.com, Railway, VPS, Docker).
   - Готовые `Dockerfile`, `docker-compose.yml`, `pure_bot.service`.

## 🛠 Установка и запуск

### 1. Переменные окружения (.env)
Создайте файл `.env` на основе `.env.example`:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=your_telegram_user_id
DATABASE_URL=sqlite+aiosqlite:///bot_dating.db
```

### 2. Локальный запуск
```bash
pip install -r requirements.txt
python run.py
```

### 3. Запуск в Docker
```bash
docker-compose up -d --build
```

### 4. Бесплатный деплой 24/7 на Render.com
1. Создайте репозиторий на GitHub и подключите его в **Render.com**.
2. Выберите тип сервиса: **Web Service** (Environment: Python 3 или Docker).
3. Добавьте Environment Variables:
   - `BOT_TOKEN`: ваш токен от BotFather
   - `ADMIN_IDS`: ваш ID Telegram
4. Render автоматически выделит порт `PORT`, на который бот ответит `200 OK`.
5. Чтобы сервис не засыпал на бесплатном тарифе, добавьте URL сервиса в бесплатный пинг-сервис (например, [cron-job.org](https://cron-job.org) или [UptimeRobot](https://uptimerobot.com)) с интервалом раз в 5–10 минут.
